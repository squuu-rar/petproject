# Еженедельный чек-лист техлида

### 1. Раз в неделю — проверка UI и звука
- Запустить сервер: `python /home/squ/petproject/main.py`
- Открыть в браузере: `http://localhost:8090`
- Проверить кликабельность плеера, ползунок громкости, перемотку (Range) и отображение обложек.

### 2. Раз в 2–3 дня — проверка прогресса в Git
- Команда: `git log -n 5 --oneline`
- Убедиться, что коммиты с префиксом `auto:` идут вперед по списку из `TASKS.md`.

### 3. При остановке прогресса — разбор логов
- Если одна и та же задача не закрывается: проверить `tail -n 50 /home/squ/petproject/daily_dev.log`
- Убедиться, что агент не застрял на падающем тесте или синтаксической ошибке.

### 4. Внешние зависимости и стриминг
- При появлении сетевых 403/капчи от YouTube: обновить пакет командой `sudo pacman -S yt-dlp`.
- Для калибровки рекомендаций: закинуть 20–50 тестовых треков в локальную папку музыки.
