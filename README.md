# Écho

Self-hosted музыкальный плеер «Écho» с персональной волной рекомендаций.

## Архитектура
- **`main.py`**: Точка входа FastAPI (REST API + раздача `static/` и стриминг аудио).
- **`db.py`**: Подключение к SQLite (`tracks.db`) и инициализация таблиц.
- **`scanner.py`** / **`importer.py`**: Модули сканирования директории с музыкой и пакетного импорта ID3/FLAC метаданных через `mutagen`.
- **`wave_engine.py`**: Алгоритм формирования автоочередности («Моя волна»).
- **`static/`**: Веб-интерфейс «Écho» (HTML/CSS/JS) для воспроизведения на ПК и смартфонах.

## Схема БД (SQLite)
- `tracks`: id, path, title, artist, album, genre, year, track_number, duration, cover_path, source, external_id, cache_path, liked, last_accessed.
- `history`: id, track_id, event (`play`/`skip`/`finish`/`like`), elapsed_seconds, timestamp.
- `playlists`: id, name, created_at.
- `playlist_tracks`: playlist_id, track_id, position.

## Как работает «Моя волна»

Профиль вкуса складывается из любимых треков, плейлистов, локальной коллекции,
дослушиваний и пропусков. Сам запуск трека не считается симпатией. Вклад событий
истории уменьшается по формуле `1 / (1 + возраст_в_днях / 30)`; вес истории
отдельного трека при выборке ограничен, чтобы повторы не вытесняли остальную коллекцию.

Для внешних рекомендаций используются YouTube Music Radio, поиск по знакомым
и похожим исполнителям и Last.fm (если задан API-ключ). Last.fm сначала ищет
похожие песни, затем использует похожих исполнителей при пустом результате.
Каналы выполняются параллельно. При сопоставлении песни с YouTube проверяются
исполнитель и название; контекстный поиск откатывается к поиску по исполнителю,
если вернул посторонние результаты.

Общий фильтр исключает недавние повторы, пропуски, дубликаты, караоке и треки
с известной длительностью вне 45–720 секунд. Пропуск исключает трек на три дня.
Исполнитель исключается при двух и более пропусках за два дня, если пропусков
больше, чем дослушиваний и лайков. Отдельно учитывается текущая сессия (45 минут).
Кандидаты ранжируются по профилю исполнителей, позитивным событиям сессии,
настроению и активности. При равных оценках сохраняется случайное разнообразие.

Для 20 треков целевые пропорции новых и знакомых: 17/3 по умолчанию, 5/15
в «Любимом», 19/1 в «Незнакомом». При нехватке коллекции очередь дополняется
новыми кандидатами; при менее пяти найденных внешних треках допускается больше
знакомых. Исполнители разносятся по очереди, если состав пула это позволяет.
Фильтр языка не снимается при пустой выдаче. В офлайн-режиме доступны только
существующие локальные файлы и файлы кэша; внешние рекомендации не запрашиваются.
Для маленькой коллекции допускается повтор недавно прослушанного трека, но
исключения по пропускам, языку, доступности и явно переданным ID сохраняются.

Это эвристическая система, без обученной модели и анализа аудиосигнала.
Язык определяется по кириллице в метаданных, инструментальность и настроение —
по ключевым словам. Эти признаки приблизительны. Поведенческие тесты используют
подмены внешних сервисов и не измеряют субъективное качество рекомендаций.

Проверка: `venv/bin/python -m pytest -q`.
